# Определение усталости человека по видеоизображению

[English version](README.md)

Прототип к магистерской работе «Разработка и внедрение алгоритма принятия решений
о состоянии человека на основе анализа видеоизображения с использованием
искусственного интеллекта».

## Установка (Windows)

Нужен Python 3.10–3.12 (python.org или PyCharm).

```
cd путь\к\папке\fatigue
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

При первом запуске программа сама скачает модель лица `face_landmarker.task`
(~3,6 МБ) с сайта Google.

## Запуск

```
python main.py                         # веб-камера
python main.py --source 1              # другая камера
python main.py --source видео.mp4      # видеофайл
python main.py --source видео.mp4 --no-display   # быстрый анализ без окна
python main.py --no-calib              # без персональной калибровки (для сравнения)
python main.py --no-closed-calib       # без этапа с закрытыми глазами (для сравнения)
python main.py --eye-mode ear          # признак глаз: ear, blendshape или fused (по умолчанию)
python main.py --no-adapt              # прежний алгоритм без адаптации к позе и артефактам
python main.py --no-hand-check         # без проверки руки у лица (быстрее)
python main.py --no-context            # без учёта времени за рулём и времени суток
python main.py --unwell                # режим «плохо себя чувствую / принимаю лекарства»
python main.py --source ночь.mp4 --start-time 03:00 --hours-driven 3   # контекст для видеофайла
```

**Калибровка** состоит из двух этапов:
1. 30 секунд сидите так, как обычно сидите за рулём (не обязательно «ровно»),
   и моргайте как обычно.
2. Через 3 секунды после надписи прозвучит сигнал — закройте глаза и держите их
   закрытыми до второго сигнала (3 секунды).

Потом ещё 10 секунд накапливаются данные, после чего система начинает выдавать решение.

Клавиши: **Q** или **Esc** — выход, **C** — заново откалибровать, **S** — снимок экрана
(для иллюстраций в работе, сохраняется в `screenshots/`), **U** — режим «плохо себя
чувствую». Клавиши работают и в русской раскладке.

При первом запуске скачивается и вторая модель — `hand_landmarker.task` (рука у лица).

Каждый сеанс записывается в `logs/session_....csv` (все признаки на каждом кадре).
Графики для главы 3:

```
python plot_session.py logs\session_20261028_150000.csv
```

| `fuzzy.py` | Нечёткий вывод Мамдани: функции принадлежности, 12 правил, центр тяжести | 2 |
| `decision.py` | Калибровка, обнаружение событий, временные окна, сглаживание, правило безопасности | 2 |

## Алгоритм

1. **Извлечение признаков на кадре:** EAR (геометрическое открытие глаз), оценка
   моргания от нейросети (blendshape `eyeBlink`), MAR (открытие рта), наклон и поворот головы.
2. **Двухточечная персональная калибровка:** признаки человека при открытых и при
   закрытых глазах. Открытость глаза считается внутри этого личного диапазона
   (0 — закрыт, 1 — открыт), глаз закрыт при открытости ниже 50%. Поэтому алгоритм
   одинаково работает при широком и узком разрезе глаз. Открытость по EAR и по
   нейросети объединяется (режим `fused`). При частоте кадров от 20 в секунду признаки
   сглаживаются медианой по 3 кадрам. Если этап с закрытыми глазами не удался,
   используется стандартный коэффициент (порог = 0,65 × личный EAR).
3. **События:** моргание, длительное закрытие глаз (≥ 0,5 с), зевок
   (рот открыт ≥ 1 с), кивок (отклонение головы ≥ 15°). Во время зевка и при сильном
   повороте головы глаза не оцениваются — это убирает ложные «закрытия».
4. **Временные окна:** PERCLOS и средняя длительность моргания — за 60 с;
   зевки и кивки — за 5 мин.
5. **Нечёткий вывод:** индекс усталости 0–100. Если одновременно сработали правила
   «устал» и «опасно», приоритет у более опасного вывода.
6. **Сглаживание и гистерезис:** уровень меняется, только если держится 3 с.
7. **Правило безопасности:** закрытие глаз ≥ 2 с — немедленная тревога и звуковой сигнал.

Уровни: **0–40 норма**, **40–70 начальная усталость**, **70–100 опасная сонливость**
(в режиме «плохо себя чувствую» — 30 и 55, тревога при закрытии глаз от 1,5 с).

## Адаптация к реальным условиям вождения

Многие водители едут не в «правильной» позе: откинувшись, облокотившись, с прищуром.
Алгоритм сравнивает водителя не с эталонной позой, а с ним самим.

| Ситуация | Что делает алгоритм |
|---|---|
| Откинулся, облокотился, сменил позу | Если голова 10 с неподвижна в новом положении при открытых глазах, это новая норма позы (а не кивок) |
| Сонный кивок | Кивок — это движение: голова медленно уходит от нормы (≥ 0,4 с) и резко возвращается (≤ 0,8 с). Ровное смещение и быстрый взгляд на приборы кивком не считаются |
| Голова откинута или опущена | Норма открытых глаз запоминается отдельно для каждого наклона (диапазоны по 5°). Учится только на уверенно открытых глазах, один раз, в пределах 70–115% калиброванной нормы |
| Прищур (солнце, привычка) | Нейросеть отдельно оценивает прищур (`eyeSquint`); при прищуре EAR не используется |
| Голова повёрнута > 30° | Используется только оценка нейросети; > 60° — глаза считаются невидимыми |
| Чихание, кашель | Короткое закрытие глаз (< 1,5 с) с рывком головы без сонного кивка не учитывается |
| Рука на глазах, у рта или носа | Вторая нейросеть (Hand Landmarker) находит руку. Рука на глазах — кадры «нет данных»; рука у рта или носа до 3 с — кашель или сморкание, дольше — поза (подпёр голову) |
| Уснул с открытым ртом | Рот открыт дольше 6 с — это уже не зевок; тревога во время зевка срабатывает через 5 с |
| Глаза закрылись, голова упала из кадра | Отсчёт закрытия продолжается — тревога срабатывает |
| Ночь, долгая езда | Время суток и время за рулём только усиливают признаки с лица (дополнительные правила нечёткого вывода); бодрый водитель тревогу не получает. После 2 ч езды — совет сделать остановку |
| Болезнь, лекарства | Система оценивает состояние, а не причину. Режим «плохо себя чувствую» повышает чувствительность |

Правило безопасности (тревога при закрытии глаз ≥ 2 с) фильтрами артефактов не отключается:
они отбрасывают только короткие закрытия.

Для сравнения в главе 3: `--no-adapt` запускает прежний алгоритм, а в журнале есть столбцы
`eye_state`, `eye_mode`, `squinting`, `hand_eyes`, `hand_mouth`, `pose_pitch`, `nod`,
`pose_change`, `artifact`, `hours`, `circadian`, `unwell`.

Параллельно считается **классический пороговый метод** (EAR < 0,25 дольше 1,5 с) —
его решения тоже пишутся в журнал, чтобы сравнить методы в главе 3.

## Что проверить на своей камере

- Посидите спокойно 2–3 минуты: должен быть уровень «Норма».
- Медленно моргайте, держа глаза закрытыми по 0,5–1 с: индекс должен расти.
- Зевните несколько раз, опустите голову: появятся зевки и кивки.
- Закройте глаза на 2–3 секунды: должна сработать тревога.

Если что-то срабатывает неправильно (например, при очках или плохом освещении),
пороги меняются в `config.py`.

## Записи с телефона

Программа обрабатывает видео с телефона без интернета:

```
python main.py --source videos\запись.mp4                    # с окном
python main.py --source videos\запись.mp4 --no-display       # быстро, без окна
python main.py --source videos\запись.mp4 --calib-start 4    # начать с 4-й секунды
```

**Калибровка по записи** (включается сама для видеофайлов): первые 30 секунд сидите как обычно,
затем закройте глаза примерно на 5 секунд в любой момент в течение следующих 25 секунд.
Программа сама найдёт этот момент в записи — секундомер не нужен.

Другие режимы калибровки: `--calib-mode guided` (с сигналами, для веб-камеры),
`--calib-mode auto` (без закрытия глаз, по первой минуте).

**Профиль водителя:** `--profile Саддам`. Если профиля нет, он создаётся после полной калибровки
(папка `profiles/`). Если есть — закрывать глаза больше не нужно, а если в начале сеанса глаза
прикрыты сильнее обычного, программа предупредит. `--profile-update` — перекалибровать профиль.

Видео крупнее 1280 по ширине уменьшается (`--max-width`). Время кадров берётся из файла —
переменная частота кадров у телефонов не мешает.

Модели `face_landmarker.task` и `hand_landmarker.task` лежат в папке программы. Интернет нужен
только если их нет; при переносе на другой компьютер копируйте их вместе с программой.

## Приложение-тестировщик на телефоне (рекомендуемый способ)

Проект `AndroidStudioProjects\FatigueMonitor`. Приложение ведёт весь сеанс само:
- спрашивает состояние (утро / после обеда / бодрость / перед сном / пробная), сон прошлой ночью и KSS до записи;
- показывает камеру с рамкой для лица, затем отсчёт 5 с;
- пишет видео фронтальной камерой (720p, без звука, горизонтально);
- подаёт сигналы голосом и звуком: 30 с «смотрите на дорогу» → «закройте глаза» (5 с) → «откройте глаза» → 10 минут → «запись закончена»;
- в основной части гасит экран, на телефон смотреть не нужно;
- после записи спрашивает KSS и заметки;
- сам ведёт `sessions.csv` в той же папке, что и видео (`calib_start` = 0, время начала точное);
- показывает, что уже записано сегодня и сколько осталось до 7 дней × 5 записей;
- напоминает утром, днём, после обеда и вечером (время меняется), если запись этого состояния сегодня ещё не сделана.

Обработка папки, скопированной с телефона по USB в `PycharmProjects\fatigue`:
```
python batch_analyze.py --phone FatigueTester --profile Саддам --compare
```

## Пакетная обработка (для главы 3)

1. Видео — в папку `videos\`.
2. Заполните `sessions.csv` (пример — `sessions_example.csv`; можно в Excel), одна строка на запись:

| Столбец | Что писать |
|---|---|
| `file` | имя видеофайла |
| `date`, `time` | дата и время начала записи (`ЧЧ:ММ` — учитывается время суток) |
| `condition` | `утро`, `обед`, `бодрость` или `перед_сном` |
| `kss_before`, `kss_after` | самооценка сонливости до и после записи (1–9) |
| `calib_start` | с какой секунды записи вы сели и начали калибровку |
| `sleep_hours` | сколько спали прошлой ночью |
| `notes` | чай/кофе, самочувствие и т.п. |

3. Запуск:
```
python batch_analyze.py --profile Саддам --compare
```
Результаты в `results\`: `summary.csv` (каждый сеанс), `by_condition.csv` (средние по условиям),
`summary.png` (графики). `--compare` дополнительно считает прежний алгоритм для сравнения.
Обработанные записи повторно не считаются (`--force` — пересчитать).

## Протокол самотестирования на телефоне

**Условия (4 вида записей):**

| Условие | Когда | Что важно |
|---|---|---|
| `утро` | через 5–15 мин после пробуждения | до чая/кофе и до умывания |
| `обед` | через 30–60 мин после обеда (обычно 13:30–15:00) | не сразу после кофе |
| `бодрость` | когда чувствуете себя обычно бодрым (10–12 или 16–18 ч) | контрольная запись |
| `перед_сном` | когда хочется спать и вы собираетесь лечь | после записи — сразу спать |

**Сколько:** по одной записи каждого условия в день, **не меньше 7 дней** (28 записей,
около 5 часов видео). Пропуски допустимы, но в каждом условии нужно не меньше 5 записей.

**Длительность записи:** 10–11 минут.

**Установка телефона:**
- **горизонтально**, фронтальная камера, на 40–60 см от лица, на уровне глаз или чуть ниже;
- неподвижно (подставка или стопка книг), каждый раз на одном и том же месте;
- свет спереди или сбоку, **не окно за спиной**;
- видео 720p или 1080p, 30 кадров/с; выключить «украшение» лица, HDR, 60 кадров/с, автокадрирование;
- режим «не беспокоить», чтобы звонки не прерывали запись.

**Чем заниматься во время записи** (имитация вождения): на ноутбуке или телевизоре за телефоном
включите длинное видео поездки по трассе (вид из машины) и смотрите на него, как на дорогу.
Сидите так, как сидите за рулём. Не берите телефон в руки, не разговаривайте, не ешьте.

**Порядок одной записи:**
1. Оцените сонливость по шкале KSS (ниже) — это `kss_before`.
2. Включите запись, сядьте в обычную позу и запомните, через сколько секунд сели (`calib_start`).
3. Первые 30 секунд — просто смотрите на экран и моргайте как обычно.
4. Закройте глаза примерно на 5 секунд, откройте.
5. Дальше 10 минут смотрите на «дорогу».
6. Остановите запись и снова оцените сонливость — `kss_after`.
7. Запишите строку в `sessions.csv` (можно в заметках телефона, потом перенести).

**Шкала сонливости KSS (Каролинская):**
1 — чрезвычайно бодр, 2 — очень бодр, 3 — бодр, 4 — скорее бодр, 5 — ни бодр, ни сонлив,
6 — есть признаки сонливости, 7 — сонлив, но бодрствовать легко, 8 — сонлив, приходится
прилагать усилия, 9 — очень сонлив, борюсь со сном.

**Первый день:** одну запись в состоянии `бодрость` обработайте с `--profile Саддам` —
это создаст ваш профиль. Дальше все записи обрабатываются с этим профилем.

**Место на диске:** 10 минут видео 720p — около 0,5 ГБ, 1080p — около 1 ГБ. Каждый вечер
переносите записи на компьютер в `videos\`.

**Безопасность:** не садитесь за руль сразу после записи «перед сном» или в сонном состоянии.
